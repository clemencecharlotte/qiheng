# 气衡｜空压站协同决策台

气衡是在 COSMO Code 平台真实开发的空压站协同决策 Web 应用。将方案提案、独立复验、人工授权、决策护照与合成执行分开，提供设备原理可视化、关系 MAP、趋势回放与只读 MCP 查询。

- 应用：https://4247-a1db149b692927f8.code.cosmoplat.cn/
- 源码基线：2026-10-15 产品 main `3fedd4ce004e194eef97037645e4f369af15318a`（r39–r43累计改件）。
- 本仓是正式提交用的独立开源快照，不含私人仓历史、凭据、个人信息截图或主办方工业原始数据。
- 文件来源及 SHA256：`SOURCE-MANIFEST.json`。清单记录导出原件；本仓新增 README、LICENSE、忽略规则不在原件清单内。

## 快速运行

Node.js 22+，npm；只读数据服务另需 Python 3.11+。

```sh
cd app
npm ci
npm run dev
```

默认开发入口为 Vite 输出的本地地址（通常是 http://localhost:5173）。游客从“序幕”进入，基础合成调度、比较与设备演示不要求模型密钥。当前标准配置未启动独立数据/MCP后端时，对应能力会显示未连接，不以静态回答冒充服务。

```sh
cd app
npm run typecheck
npm test
npm run build
```

正式平台部署使用 `app/vite.m17r01.config.ts`，与默认本地配置不同。该配置依赖服务端能力令牌，缺失即拒绝启动，不能为方便演示关闭鉴权。

## 目录与功能

| 目录 | 内容 |
| --- | --- |
| `app/` | React / TypeScript / Vite前端、求解器、独立复验、护照、合成执行、界面及测试 |
| `services/agent-mcp/` | 正规MCP SDK的stdio服务和同源网关、只读工具、资源、取消与超时保护 |
| `services/readonly-data/` | Python/SQLite离线批次接入及数据质量治理服务 |

独立服务的部署、端口、精确Origin及服务端鉴权要求见各自 README。令牌只保存在服务端，不可放入前端或提交Git。仅提供空值示例，不提供任何真实服务凭据。

## 能力边界

- 所有演示与评测数值为固定种子合成数据上的模型结果，不是现场节能收益或赛题指标达标证明。
- 不连接生产PLC/SCADA，不控制真实设备；AC-03安全边界未核实，只读展示、不参与自动调度。
- 批准不自动开始；故障使旧授权失效；第二次故障组合前缀续算未实现时安全阻断。
- 在线模型推理未连接；只读MCP调用与在线大模型推理是不同能力。
- 设备原理动画为教学示意，不代表在线遥测或实际设备可启动。
- 当前标准本地构建与COSMO线上代理部署不是同一服务配置，不能仅凭健康响应宣称协议或多租户授权已验收。
